# Tailwind port audit — velqu-view UI/UX upgrade

Extracted from the proven Tauri UI (lekuvo develop) for porting to the velqu-view line (main).

## Method
1. This vocabulary comes from every className in the develop frontend (NotchOverlay, panels, SystemPanel, AiPanel, HomePanel, App).
2. Diff each class against `velqu-view/crates/velqu-tailwind/src/compile.rs` (the class->declaration compiler); write a harness test that compiles this list and reports every unsupported class.
3. Implement by priority: layout (absolute/inset/z-index/pointer-events) -> spacing/size arbitrary values -> colors with opacity (/NN, [0.06]) -> shadows (arbitrary box-shadow) -> transitions/animation (duration/ease/transition-[width], wave-bar/hint-bounce keyframes per the velquview-animation-plan memory).
